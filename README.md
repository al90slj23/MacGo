# Mac Go

**一个入口，放下常用的 Mac 小工具。**

Mac Go 是原生 Swift / AppKit 工具集合，目前包含独立窗口切换、窗口预览、风扇控制与温控规则。各工具保留自己的设置，共用语言、启动选项和授权入口，无第三方运行时依赖。

项目地址：[al90slj23/MacGo](https://github.com/al90slj23/MacGo)

## 功能

### 窗口切换

- 默认使用 **Cmd + Tab** 按独立窗口切换，支持 Option + Tab、其他预设或自定义快捷键。
- 按最近使用顺序选择窗口；支持反向选择、方向键、Enter 确认和 Esc 取消。
- 鼠标悬停更新选中框，点击立即切换；卡片右上角的 × 正常请求退出整个对应应用，由该应用处理未保存内容提示。
- 窗口卡片按窗口比例紧凑排布，应用图标位于预览左上角，标题单行显示。缩略图按实际显示尺寸与屏幕像素密度捕获。
- 无窗口应用默认显示在独立的底部横向栏，只供鼠标选择，不进入键盘循环；可在窗口切换设置中关闭。
- 支持集中显示或按显示器分组，以及仅作用于窗口切换工具的应用排除列表。

### 风扇控制

- 查看设备实际支持的风扇转速、控制模式、硬件允许范围和温度传感器；缺失读数不会显示为零。
- 提供系统自动、最大、手动和自定义四种模式，主窗口与菜单栏面板共用一个控制会话。
- 自定义规则支持传感器、温度阈值、指定风扇和转速百分比；支持开机延迟、每日控制时段与跨午夜时段。
- 菜单栏可显示转速、CPU 温度及图标动画；温度单位可选摄氏或华氏。
- 手动控制需要安装本机控制服务。退出、睡眠、断联或异常状态下，会尝试恢复本工具持有的风扇控制，并保留失败恢复记录。

具体机型的传感器和写入能力取决于硬件与固件。模拟测试、请求被接受和实际转速达标是不同的验证结果，见 [验证状态](docs/VALIDATION.md)。

## 系统要求

- macOS **13 或更新版本**。
- 窗口缩略图需要 macOS **14 或更新版本**；macOS 13 仍可按图标和标题切换。
- 从源码构建需要提供 Swift 5.9 或更新工具链及 macOS SDK 的 Xcode 环境。

## 构建与安装

```sh
git clone https://github.com/al90slj23/MacGo.git
cd MacGo
swift test
bash scripts/build-app.sh
bash scripts/install-local.sh
```

构建产物为 `dist/Mac Go.app`，安装位置为 `~/Applications/Mac Go.app`。安装前退出正在运行的旧版本；安装脚本会保留回退副本并刷新应用注册。

默认构建使用本地临时签名，尚未公证。构建和安装应用不会安装风扇控制服务或设定转速。若已有开发者签名身份，可显式设置：

```sh
CODE_SIGN_IDENTITY='Developer ID Application: …' bash scripts/build-app.sh
```

## 设置与授权

| 位置 | 内容 |
| --- | --- |
| 通用 → 基础设置 | 语言、登录启动、菜单栏显隐 |
| 通用 → 授权 | 所有工具实际需要的系统权限与服务 |
| 窗口切换 | 快捷键、外观、多屏布局、无窗口应用栏、独立排除列表 |
| 风扇控制 | 转速、温控规则、温度单位和控制时段 |

授权页每项都提供对应入口，实际就绪后显示绿色勾选。

- **辅助功能**：识别并切换窗口，需要用户为当前应用授予权限。
- **屏幕录制，可选**：仅用于独立窗口缩略图。预览有内存上限，不录音、不保存到磁盘；不授权仍可按标题和图标切换。
- **风扇控制服务**：读取转速不需要管理员权限。手动调速时，先在应用内审阅服务变更，再由 macOS 请求管理员确认；应用不接触或保存管理员密码。

本机风扇服务按当前用户和当前构建的精确签名身份校验连接，只接受受限的风扇操作。临时签名构建更新后，可能需要重新授予窗口权限并重新确认控制服务。Mac Go 不修改 TCC 数据库、不绕过 SIP，也不创建通用管理员命令入口。

为接续早期开发版的设置与服务，内部应用标识和风扇服务标识暂保留 `local.mactoolbox.*`，部分内部 helper 名称也保持兼容；产品名称与应用包名称统一为 **Mac Go**。
