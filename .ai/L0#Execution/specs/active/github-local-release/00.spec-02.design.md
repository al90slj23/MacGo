# GitHub 与本机更新设计

根 shell 入口转交 Python 发布协调，复用已有 Swift 构建及原子安装脚本。步骤串行、并发锁保护，源码/HEAD/候选清单和包内容封存到本机忽略回执。

GitHub 模式核对预期 origin/分支/远端祖先关系，精确暂存候选，提交前后检查变化，推送后核对远端 SHA。只读状态/计划不产生安装或推送。

本机更新先验证候选，正常退出已核实身份的应用，再安装固定路径、保留旧包、刷新注册、启动并核对 PID/UID/可执行路径/版本及源码身份。运行回执是受限本机元数据，不包含窗口内容。特权服务和 TCC 仍经原生流程单独授权，不自动输入管理员密码。
