# 规格生命周期

每个规格目录使用四个文件：`00.spec-01.requirements.md`、`00.spec-02.design.md`、`00.spec-03.tasks.md`、`00.spec-04.decisions.md`。

- `backlog/`：尚未开始且不索取新权限。
- `active/`：当前实现、验证或仍有必要外部验收。
- `completed/`：适用要求已完成；保留对应构建与验证边界。

完成任务后更新状态并归档，L2 稳定导航同步指向新位置。模拟/源码测试与本机功能验收分别记录，不因一项成功关闭其他待办。没有接入的 IDE 不创建伪映射或声称自动触发。
