# Mac Go 命名与兼容

遵循已有 SwiftPM、Swift 与 AppKit 约定，名字表达具体职责；“路径为王”在本项目用于模块所有权和可定位性，不生成 Web API 或数据库表。

| 对象 | 约定 |
| --- | --- |
| 产品/应用包 | `Mac Go` / `Mac Go.app` |
| SwiftPM 主包、target、product、可执行文件 | `MacGo` |
| Swift 类型与文件 | 类型使用 UpperCamelCase；主类型与文件对应，如 `WindowCatalog.swift` |
| Swift 方法、属性、局部变量 | lowerCamelCase，保留行业通用术语如 AX、XPC、SMC、RPM、UID |
| Python/ shell 工作流 | 描述职责的文件名；Python 函数遵循其语言约定，不机械套 Swift 风格 |
| 当前规格目录 | 小写连字符，如 `github-local-release`；四份 `00.spec-*` 标准文件 |

原 `local.mactoolbox.*` 标识、`MacToolboxFanHelper`、偏好命名空间属于兼容接口，按已实现迁移保留。新的命名规则不能用于静默改写签名要求、服务归属、持久化字段或旧授权数据。需要语义迁移时单独记录兼容、回退和验证方案。

避免没有领域含义的通用 `manager`、`helper`、`util` 命名；既有系统 helper target 不因形式统一而改名。目录名保留 SwiftPM 惯例 `Sources/`、`Tests/`、`Resources/`。
