# 错误、恢复与状态

失败应显示具体步骤和仍然成立的结果。代码编译、服务安装、身份连接、请求接受、模式/目标稳定和实际 RPM 达标分别报告；不以图标动画或绿色文字掩盖未完成状态。

- 有界等待与重试须保持连接代次/请求身份匹配；停止自动重复写入以避免风扇反复升降。
- 所有权与恢复记录先于手动写入保存，只有确认系统自动模式后清除；恢复失败保留记录并可见。
- 安装/发布失败须保留旧应用和诊断证据。明确 GitHub 是否已经更新、本机是否已经替换、是否启动及权限是否仍需用户操作，不把部分成功输出成完整发布成功。
- 运行回执仅记录核对版本和进程所必需的数据，保存在本机忽略目录；不写入窗口画面、标题或管理员凭证。
- 缺失温度/模式/系统权限不能伪造默认成功；缺失温度不显示为 0。

硬件和权限具体边界以 [原生 macOS 规范](01.arch-03.native-macos.md) 为准。
