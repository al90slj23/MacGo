# Git 与发布范围

- 按任务隔离候选文件，保留无关 WIP；暂存前审阅精确路径与差异，不执行整仓 `git add -A`。
- 提交信息清楚说明问题与结果，可用 `feat`、`fix`、`docs`、`test`、`refactor`、`chore` 范围；不为了模板格式重写已有提交。
- GitHub 统一目标为 `al90slj23/MacGo` 的 `main`，发布流程核对 fetch/push URL、分支、远端祖先关系及远端 SHA。遇到分叉/进行中的 merge、rebase 或 cherry-pick 即停止，禁止自动强推、自动变基。
- 发布验证基于封存的源码内容、Git HEAD、候选路径和签名包指纹。并发或钩子改变源码/索引时重验，不将验证结果移用到另一个树。
- 公开仓库只提交可发布源码、测试、资源和文档；构建、模型、检索缓存、`.ai` 备份、发布/运行回执、本机画面/标题/进程清单、签名授权清单、凭证和第三方二进制不提交。
- `ZERO/` 是独立忽略的模板克隆，不暂存为偶然 gitlink。Mac Go 项目变更和 ZERO 上游变更分别管理。
- GitHub 推送、本机安装/运行、系统权限及实际功能分别验收。一次发布可只做本机更新，不能因此创建 Git 提交或推送。

完整操作入口见 [gogogo.sh](09.tool-01.gogogo-sh.md)。
