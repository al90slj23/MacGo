# Mac Go 开发入口

首先读取 [项目事实](zero-project-facts.md)、本指南和 [L2 目录](../L2%23Index/toc.md)，然后定位当前 L0 规格及相关 L3 规范。所有改动均须遵守 [原生 macOS 规范](../L3%23Standards/standards/01.arch-03.native-macos.md)。

## 本项目边界

这是一个原生 macOS 工具集合。工具自己的启用、规则和黑名单在该工具下；语言、登录启动、菜单栏显隐和授权入口可共享。不能用另装独立软件代替模块实现。

系统权限由当前进程真实 API 检测。录屏只用于可选缩略图，风扇读取无需管理员权限；风扇写入仅限经过精确签名身份验证的内置服务。安装应用、服务绑定、请求 ACK 和实际硬件表现不能混为同一验收。

本项目发布只有 GitHub 源码推送和更新本机 `Mac Go.app`。没有线上环境。先校验封存源码/构建，再做所选发布步骤；保留无关 WIP 和本机回退副本，原生管理员验证由用户完成。

## 知识与检索

- L0 维护当前规格、执行配置及工作流；L1 只摘要，L2 只导航，L3 是唯一当前规范与参考正文，L4 保存有日期的历史，L5 是可重建的查询层。
- 已知路径或符号直接读取需要的范围；未知主题先小范围 QMD `lex`（通常 3 条、关闭 rerank），代码关系先小范围 CodeGraph（通常 `maxFiles: 3`）。仅在需要时扩展或使用语义查询。
- 复用当前可见且未变化的源码与证据；检索不可用最多一次针对性重试，再在所属目录使用 `rg` 和范围读取。
- `.ai` 源 Markdown 修改批量完成后，收尾只运行一次 `bash .ai/L0#Execution/workflows/local/retrieval-indexes.sh refresh`。只读任务、原文未变不刷新。失败须处理或明确报告实际可用范围。
- 工具、模型、索引和运行元数据放在忽略的 `.ai/L5#Knowledge/.generated/`；`ZERO/` 是模板克隆，不是应用依赖。检索结果只能帮助定位证据。
- MCP 配置文件存在不代表工具已连接；客户端重连和按正常机制信任后才能单独验收。当前没有安装原生 Codex Stop hook。

初次引入验收见 [ZERO 适配规格](../L2%23Index/zero-onboarding.md)，采用的模板工作方式见 [ZERO 指南](zero-template-guide.md)。模板中的非适用 Web/API/数据库或部署示例不约束本项目。
